# Personal Portfolio Site

A professional personal portfolio website showcasing my skills, projects, and professional experience as a full-stack software developer.

## About

This is a responsive portfolio website built with HTML, CSS, JavaScript, and PHP. It serves as a central hub to display my technical expertise, completed projects, work experience, and contact information.

## Features

- **Home Page**: Eye-catching hero section with animated text and particle effects
- **About Section**: Professional biography, work experience, and educational background
- **Skills Page**: Detailed breakdown of technical competencies including:
  - API Design
  - Web and Mobile Development
  - SEO Optimization
  - Automation
  
- **Projects Showcase**: Interactive carousel displaying featured projects:
  - FASPRO24 - Facility Management Application
  - SHOWBAY24 - Hybrid Virtual Events Platform
  - Sinansel Marketplace - International Marketplace Platform
  - PropertyTV - Video Subscription Platform
  - Kleekle - Photography Platform
  
- **Contact Form**: Direct messaging capability with email integration
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Dark Theme**: Modern dark interface with accent colors

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP
- **Libraries**: 
  - Bootstrap (CSS Framework)
  - jQuery
  - Owl Carousel (Image galleries)
  - Typed.js (Text animations)
  - Particles.js (Background animations)
  - Magnific Popup (Image lightbox)

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. Navigate through the different sections using the top navigation menu
4. Download CV from any page using the "Download CV" button
